# Generated outputs

Run `python main.py train` after installing dependencies and downloading the authentic dataset. The pipeline creates the metrics, figures, model, reports, processed records, held-out demonstration patients and prediction directories documented in the project README.

Values are generated from the actual run. Project packaging may include an aggregate verification report, while raw patient data is acquired separately. Review generated patient-level files before publishing them. Spark writes CSV directories with `part-*.csv` files. Choose another `--output` directory to retain multiple runs.
